Source: ESPN roster snapshots collected by GitHub Actions and served by this GitHub Pages site. No browser CORS proxies are used. Results are coverage-limited, not certified complete all-time league populations. Historical scans request available season rosters, and may be blocked or omit archived players. Active means present in the currently returned roster, not independently verified contract status. Multi-league athletes are deduplicated by ESPN ID only within each league; cross-league identities are not merged. Player-seasons count distinct league/player/year combinations. Data is cached locally using IndexedDB.
